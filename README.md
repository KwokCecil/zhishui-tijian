# 智税体检（zhishui-tijian）

> AI × 税务 Demo：模拟"金税四期视角"的企业税务健康检查工具。
> 上传/生成企业的发票、资金、人资、合同等模拟数据，输出：
> **风险画像（评分 + 等级 + 命中特征清单 + 监管视角 Top3）+ 优惠政策清单 + 行动建议**。

## 快速开始

```bash
pip install -r requirements.txt

# 1. 生成演示数据（clean/risk/fuel/case1/case6 五个场景）
python generate_data.py --all

# 2. 运行验收测试（25 条）
python tests/run_tests.py

# 3. 启动演示页面
streamlit run app.py
```

## Agent 工具层

工具 = 税务知识。判断全部封装在工具里（规则/政策卡片/小微判定），
LLM 只负责理解意图、决定调用哪个工具、把事实组织成回答。

可用工具：

| 工具 | 输入 | 输出 |
|---|---|---|
| run_tax_health_check | profile + 发票/资金/合同 JSON | 命中特征 + 评分 + 等级 + Top3 |
| match_policy_cards | profile | 优惠政策清单（可享受/需确认/不适用，带文号） |
| check_small_micro | profile | 小微四项条件逐项判定 |
| answer_policy_question | query | 未收录政策的统一拒绝（引导 12366） |
| get_demo_scenario | clean/risk/fuel/case1/case6 | 内置场景四类数据 JSON |
| generate_report | hits + summary + matched | Markdown 体检报告 |

两种运行模式：

1. **离线演示模式（默认，无需 key）**：关键词路由直接调用工具，页面展示
   "意图→工具→事实→回答"的完整轨迹。用于面试演示和开发调试。
2. **在线 Agent 模式**：配置模型 API 后，由 LLM 自主决定调用哪些工具
   （真实 function calling 循环）。

配置环境变量（或 Streamlit secrets）：

```bash
set ZHI_SHUI_LLM_API_KEY=sk-xxx
set ZHI_SHUI_LLM_BASE_URL=https://api.deepseek.com/v1
set ZHI_SHUI_LLM_MODEL=deepseek-chat
```

兼容任何 OpenAI 格式的模型服务（DeepSeek、通义、豆包、硅基流动等）。

## 诚实边界（面试必讲）

- 金税四期的具体模型、阈值、权重不公开。本工具使用**公开可见的风险逻辑 + 演示阈值**，定位是**企业自查工具**，不是监管工具。
- 所有数据为模拟数据，非真实企业；报告含免责声明。
- 判定全部由规则完成（可解释、可测试、可留痕），LLM 只做报告翻译（当前为规则版，LLM 报告为加分项）。
- 生产环境需按地区、行业、主管税务机关口径校准阈值。

## 场景说明

| 场景 | 用途 |
|---|---|
| clean | 全正常数据，应输出低风险画像 |
| risk | 软件企业混合风险种子（税负率低/三流不一致/个税社保差异/上游走逃/顶额开票/红冲偏高/小微临界等） |
| fuel | 加油站模板（以进控销 + 三源比对 + 设备信任梯度） |
| case1 | 光伏设备制造企业：约120人、资产未临界、收入上亿、应税所得 292.7 万（距300万仅7.3万）、研发加计 600 万（小微临界预警链） |
| case6 | 农产品收购发票：收购对象身份存疑 + 单户金额异常 + 业务流不匹配 |

页面顶部会显示当前场景的**企业画像、风险种子、预期结论**，跑完自动给出
“关键结论”横幅（最高关注特征 + 等级）和四项指标卡。

## 评分口径

- **风险指数（0-100，越高越危险）** = 基础分 + 组合加成（封顶100）。
- 基础分：高危 45 分/条、中危 20 分/条、低危/提示 5 分/条。
- 组合加成仅一条：小微临界家族（601 或 001）+ 604 收入利润不匹配 +25。
- 等级由指数直接推导：≥60 高风险；20-59 中风险；<20 低风险。
- 规则层级：001 是 601（所得临界）+ 602（大额调减）的组合规则，
  组合规则用 0xx 独立编号、单独执行，同时命中时 601/602 并入 001 不重复计分。
- 规则分类：三位编码 = 第一位业务大类 + 后两位序号
  （发票/资金/上下游/申报/人资信用/资格优惠/数据质量/行业模板/关联团伙），
  只登记已实现规则，新增按类顺延；组合规则独立编号（001 起），评分层的组合加成是另一层概念。
- 政策互斥：P101 小微低税率与 P102 高新15% 互斥，同一所得择优适用，小微 5% 更优。
- 风险-政策联动：P101/P301↔601/001/604、P102↔605、P103↔603，命中相关风险时提示“享受前提”，
  所有场景通用，不针对单个案例。
- 六税两费适用对象：小规模纳税人、个体工商户、小型微利企业；P104 负面清单为限制规则，
  命中=不得享受，未触发=不影响。
- 例：案例一命中 001(20)+604(20)=40 基础分（601/602 已并入 001），组合 +25 → 65/100 → 高风险；
  案例六命中 804(45)+805(20)=65 → 高风险；2 条高危 = 90 → 高风险。
