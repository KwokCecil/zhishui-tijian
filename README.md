# 智税体检（zhishui-tijian）

> AI × 税务 Demo：模拟"金税四期视角"的企业税务健康检查工具。
> 上传/生成企业的发票、资金、人资、合同等模拟数据，输出：
> **风险画像（评分 + 等级 + 命中特征清单 + 监管视角 Top3）+ 优惠政策清单 + 行动建议**。

## 快速开始

```bash
pip install -r requirements.txt

# 1. 生成演示数据（clean/risk/fuel/case1/case6 五个场景）
python generate_data.py --all

# 2. 运行验收测试（25 条）
python tests/run_tests.py

# 3. 启动演示页面
streamlit run app.py
```

## 项目结构

```
zhishui-tijian/
├── generate_data.py      # 生成四类模拟数据（企业指标/发票/资金/合同），内置风险种子
├── rules.py              # 风险特征库：每个特征一个函数，统一输出结构
├── scoring.py            # 风险评分（演示权重：高3/中2/低1，100-命中加权分）
├── policies.py           # 政策卡片匹配（机会筛查模块）
├── app.py                # Streamlit 页面：上传/选场景 → 报告
├── config/policy_cards.json  # 首批政策卡片（8 张核心卡，文号待官网复核）
├── tests/run_tests.py    # 25 条验收用例（对应 Demo 方案第 10 节）
└── data/                 # 生成的模拟数据
```

## 诚实边界（面试必讲）

- 金税四期的具体模型、阈值、权重不公开。本工具使用**公开可见的风险逻辑 + 演示阈值**，定位是**企业自查工具**，不是监管工具。
- 所有数据为模拟数据，非真实企业；报告含免责声明。
- 判定全部由规则完成（可解释、可测试、可留痕），LLM 只做报告翻译（当前为规则版，LLM 报告为加分项）。
- 生产环境需按地区、行业、主管税务机关口径校准阈值。

## 场景说明

| 场景 | 用途 |
|---|---|
| clean | 全正常数据，应输出低风险画像 |
| risk | 软件企业混合风险种子（税负率低/三流不一致/个税社保差异/上游走逃/顶额开票/红冲偏高/小微临界等） |
| fuel | 加油站模板（以进控销 + 三源比对 + 设备信任梯度） |
| case1 | 光伏设备制造企业：收入上亿、应税所得 292.7 万、研发加计 600 万（小微临界预警链） |
| case6 | 农产品收购发票：收购对象身份存疑 + 单户金额异常 + 业务流不匹配 |
